# 🏫 CampusFix AI

## Intelligent Campus Problem Detection, Prioritization
## and Resolution System

CampusFix AI is an AI-powered campus problem management
system designed to automatically analyze student complaints,
classify problems, estimate severity, prioritize issues and
recommend the appropriate department for resolution.

## 🚀 Features

- AI-based issue classification
- Severity estimation
- Priority scoring
- Department routing
- NLP-based complaint analysis
- Complaint tracking
- Campus analytics
- Recurring issue detection
- Administrative dashboard

## 🧠 AI Technologies

- Machine Learning
- Natural Language Processing
- Knowledge Representation
- Classification
- Statistical Analysis
- Intelligent Decision Making

## 🛠️ Technologies

- Python
- Scikit-learn
- XGBoost
- Pandas
- NumPy
- NLTK
- Streamlit
- Plotly
- Git/GitHub
