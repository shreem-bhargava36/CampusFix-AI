# CampusFix AI — Project Statement

## Project Title

CampusFix AI — Intelligent Campus Problem Detection,
Prioritization and Resolution System

## Problem Statement

Students frequently encounter campus infrastructure and
service-related problems such as damaged furniture, electrical
issues, water leakage, cleanliness problems, network failures
and other maintenance issues.

Traditional complaint systems generally depend on manually
categorizing and prioritizing these complaints. This can result
in delays, incorrect routing and difficulty identifying recurring
problems.

CampusFix AI aims to develop an intelligent system that analyzes
student complaints using Artificial Intelligence, Machine Learning
and Natural Language Processing. The system will classify the
reported problem, estimate its severity, determine its priority,
and recommend the appropriate department for resolution.

## Scope

The system will allow students to:

- Submit campus complaints
- Describe problems using natural language
- Optionally upload an image
- Track complaint status
- View AI-generated issue classification

The system will allow administrators to:

- View submitted complaints
- Prioritize complaints
- View issue categories
- Assign complaints to departments
- Track resolution status
- Analyze recurring campus problems

## Target Users

### Students
Students can report campus problems and track their complaints.

### Campus Administration
Administrators can monitor, prioritize and manage reported
campus problems.

### Maintenance Departments
Departments can receive appropriately categorized and prioritized
complaints.

## High-Level Features

1. AI-based issue classification
2. Complaint severity estimation
3. Intelligent priority calculation
4. Department recommendation
5. NLP-based complaint analysis
6. Complaint tracking
7. Campus issue analytics
8. Recurring problem detection
9. Administrative dashboard
